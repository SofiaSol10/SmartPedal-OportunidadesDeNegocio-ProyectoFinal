## Descripcion del proyecto

SmartPedal es un proyecto de I+D universitario que combina:
- Bicicletas de pedaleo asistido (motor 250W nominal, sin acelerador)
- Sensores IoT de bajo consumo (GPS/GNSS, giroscopio, BMS inteligente)
- App movil conectada via BLE para telemetria, inmovilizacion remota y alertas
- Modelo de financiamiento mensual estudiado para la realidad economica limena

> Aviso academico: Esta es una landing page de mockup en etapa de validacion de mercado. No constituye oferta comercial activa.

## Despliegue en GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a **Settings > Pages**
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`
4. Guarda los cambios
5. En pocos minutos tu landing estara disponible en `https://<usuario>.github.io/<repo>/`
