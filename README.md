## Sobre SmartPedal

SmartPedal combina innovación en hardware y software para resolver la movilidad urbana:
- Bicicletas de pedaleo asistido (motor 250W nominal, sin acelerador de puño)
- Sensores IoT de bajo consumo (GPS/GNSS, giroscopio y BMS inteligente)
- App móvil conectada para telemetría, inmovilización remota y alertas preventivas
- Planes de suscripción y financiamiento adaptados a la realidad de Lima

> Aviso de validación: Esta landing page se encuentra en fase de validación comercial y pruebas técnicas preliminares.

## Despliegue en GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a **Settings > Pages**
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`
4. Guarda los cambios
5. En pocos minutos tu landing estará disponible en `https://<usuario>.github.io/<repo>/`
